## Ruling H-1 — The renderer: Python writes SVG into one self-contained HTML file. No library, no download, no server.

> **H-1. `era_ph5_dashboard.html` is generated by `era_ph5_build_html.py` from the four grains and the style
> tokens, using the Python standard library only.** Every view is an inline `<svg>` written by the build
> script (`era_ph5_views.py`, one function per view). Every mark that shows a number carries the field it came
> from as data attributes. The four grains are embedded in the page verbatim as JSON alongside the manifest's
> md5s. The page contains no `<script src>`, no `<link>`, no `<img>` other than a `data:` URI, no font import
> and no URL that a browser would fetch. It opens from disk, from an email attachment, and from any static
> host, identically. Type is `Helvetica Neue, Helvetica, Arial, sans-serif` per the tokens — a system stack, so
> nothing is fetched.

**Why SVG and not a charting library.** §0.5. Also: an architecture portfolio prints. SVG prints and exports to
PDF at any scale; a canvas-rendered chart does not.

**Why static and not a server.** The page is a snapshot of the grains at build time, which is what every Tableau
option delivered too (E ruling §0.5). "Continuous update" is one scripted chain (H-3), not a live connection.
A server (Dash, Streamlit) adds hosting cost and surface for nothing this project's cadence needs. Default
stated and applied: static.

**Interactivity, bounded.** Two controls, as 5B specified: `p. Metro` (V2's selected metro, saved on Columbus —
F5B-7) and `p. Basis` (the metered swap, saved OFF / IT). Both are implemented by pre-rendering every state
into the SVG and toggling visibility with a few lines of inline vanilla JavaScript. **The page must show its
saved state with JavaScript disabled** — content never depends on script. Hover detail is a `<title>` child
on the mark, native to SVG. Nothing else animates or transitions.

**Determinism.** Two builds from the same grains and tokens produce byte-identical HTML. No timestamps except
the manifest's `written_utc`, no random ids, dictionary keys in sorted order. The gate re-runs the build into
scratch and asserts equality (H-4, group H).
